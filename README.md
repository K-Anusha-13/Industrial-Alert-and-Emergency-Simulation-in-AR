# Industrial Alert and Emergency Simulation in AR

A web-based **Augmented Reality (AR)-inspired industrial safety training simulator** designed to replicate real-world emergency scenarios and improve response decision-making in industrial environments.

---

## Project Overview

This project simulates critical industrial emergencies within a virtual factory environment using interactive UI elements and AR-like overlays. It enables users to understand, practice, and respond to hazardous situations in a controlled digital setup.

The system focuses on **safety awareness, rapid response training, and procedural accuracy**, which are crucial in real-world industrial operations.

---

## Key Objectives

* Simulate real-world industrial emergency situations
* Provide an interactive and engaging safety training platform
* Improve user decision-making under time constraints
* Demonstrate AR-based visualization concepts using web technologies

---

## Core Features

### Scenario-Based Emergency Simulation

* Fire Emergency
* Gas Leak Detection
* Electrical Hazard
* Mass Evacuation

Each scenario includes:

* Hazard visualization
* Guided instructions
* Time-bound execution

---

### Interactive Decision System

* Action-based controls (Alarm, Evacuation, Shutdown, etc.)
* Correct sequence validation
* Real-time feedback on user actions

---

### Performance Tracking

* Live timer 
* Score calculation 
* Progress tracking bar 
* Completion-based evaluation

---

### AR-Inspired Visualization

* Hazard indicators with dynamic animations
* Real-time information overlays
* Visual evacuation route guidance

---

### Immersive Experience

* Sound effects using Web Audio API
* Animated hazard effects (fire, gas, electrical)
* Particle-based visual enhancements

## How It Works

1. Select an emergency scenario
2. Hazards appear dynamically on the factory layout
3. AR-style instructions guide the user
4. Perform the required actions in the correct order
5. System evaluates performance based on:

   * Accuracy
   * Response time
   * Completion

---

## Evaluation Criteria

*  Correct sequence of actions
*  Time efficiency
*  Final score
*  Task completion percentage
